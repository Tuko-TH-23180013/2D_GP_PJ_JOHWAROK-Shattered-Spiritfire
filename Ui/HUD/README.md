# 조화록 데모 HUD

사용자 제공 `UI_DEMO/JOHWAROK_HUD_v0_3`의 PNG를 변경 없이 분류했다. 콘셉트 이미지와 같은 정보 배치를 따르는 저해상도 **데모** 에셋이며 최종 아트가 아니다. 원본 자료는 참조용으로 보존한다.

- `player`: 초상화, 하단 패널, HP 프레임/채움
- `weapons`: 기본/거대 방망이 아이콘
- `dash`: 충전/빈 불꽃
- `abilities`: A/S 패널과 잠금/후속 능력 아이콘
- `boss`: 보스 패널, HP/스태거 프레임과 채움
- `currency`: 실제 보유 혼불 재화 표시용 데모 리소스
- `common`: 선택/비선택 슬롯
- `location`: 게임 진행 데이터와 분리된 지역 표시명

`reference_layout.json`은 제공된 1280×720 좌하단 기준 원본 배치다. 실제 게임은 바닥 y=100 아래로 HUD를 배치하도록 별도 렌더러에서 크기/좌표를 조정한다. 원본의 대시 아이콘이 화면 밖으로 잘리는 배치는 가져오지 않는다. HUD가 전투 수치나 상태를 변경하지 않는다.

예시 HP 87/110, 재화 105/7과 예제용 키 바인딩은 가져오지 않는다. 두 능력 슬롯은 거대화/축지의 독립 쿨타임, 장착 표시, 버프 지속시간을 표시한다. 기존 아이콘은 데모 대체 이미지다. 재화는 실제 판 골드만 표시한다. 장비창은 equipment_ui.py에 분리하며 게임 상태 변경은 클릭 처리에서만 수행한다.

`model.py`는 비율 제한/대시 순차 회복/보스 표시 조건, `renderer.py`는 실제 렌더링을 맡는다. 지역 패널은 동봉 currency_panel의 빈 장식 테두리를 재사용한다. 모든 PNG는 원본과 동일하며 리소스 로드는 __file__ 기준이다. 폰트는 Windows 시스템 맑은 고딕을 사용 가능할 때만 참조하며, 없는 환경은 기존 동봉 폰트와 영문으로 대체한다. 이미지/레이아웃 조정은 임시 값이다.
