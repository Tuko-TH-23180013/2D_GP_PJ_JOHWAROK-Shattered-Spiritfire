# 조화록 데모 HUD

사용자 제공 `UI_DEMO/JOHWAROK_HUD_v0_3`의 PNG를 변경 없이 분류했다. 콘셉트 이미지와 같은 정보 배치를 따르는 저해상도 **데모** 에셋이며 최종 아트가 아니다. 원본 자료는 참조용으로 보존한다.

- `player`: 초상화, 하단 패널, HP 프레임/채움
- `weapons`: 기본/거대 방망이 아이콘
- `dash`: 충전/빈 불꽃
- `abilities`: A/S 패널과 잠금/후속 능력 아이콘
- `boss`: 보스 패널, HP/스태거 프레임과 채움
- `currency`: 후속 재화 시스템용 보존 리소스
- `common`: 선택/비선택 슬롯

`reference_layout.json`은 제공된 1280×720 좌하단 기준 원본 배치다. 실제 게임은 바닥 y=100 아래로 HUD를 배치하도록 별도 렌더러에서 크기/좌표를 조정한다. 원본의 대시 아이콘이 화면 밖으로 잘리는 배치는 가져오지 않는다. HUD가 전투 수치나 상태를 변경하지 않는다.

예시 HP 87/110, 재화 105/7과 예제용 키 바인딩은 가져오지 않는다. A/S는 미구현 잠금 슬롯이다. 재화는 실제 시스템 연결 전까지 표시하지 않는다.
