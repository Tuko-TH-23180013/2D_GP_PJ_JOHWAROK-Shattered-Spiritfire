# 조화록 2차기획

문서 버전 v0.13 · 작성 2026-11-23 · 갱신 2026-11-26 · Python/Pico2D

## 1. 문서 목적과 관리

초기 기획 이후 추가된 전투 성장, 특수 아이템, 라운드 보상, 상점, 각인 시스템을 기록한다. VS Code의 Codex가 추가 개발을 이어갈 때 사용하는 기획 기준 문서다.

앞으로 추가·변경되는 기획은 이 문서에 누적하고 버전과 변경 이력을 갱신한다. 기본 파일명은 `JOHWAROK_2차기획.md`로 유지한다. 로컬 프로젝트에서는 `docs/JOHWAROK_2차기획.md` 배치를 권장한다. 이후 수정 시 기존 문서의 최신 내용을 먼저 확인한다.

‘합의 방향’은 대화에서 사용자가 선택하거나 동의한 구조다. ‘시험안’은 효과와 수치를 검증하기 위한 제안이다. ‘미정’은 추가 결정이 필요한 항목이다. 이 문서의 기획 내용을 구현 완료로 기록하려면 실제 최신 소스와 실행 결과를 확인해야 한다.

## 2. 성장 시스템의 합의 방향

- 장르는 빠른 전투와 플랫포머 이동을 중심으로 하는 2D 횡스크롤 액션이다.
- 데드셀 같은 반복 도전과 아이템 수집의 느낌을 참고하며, 로그라이크 요소의 복잡도는 가볍게 유지한다.
- 폼 관련 해금·성장은 영구 재화 구매 같은 장기 성장으로 둔다. 라운드 보상으로 폼 성장 선택지를 무작위 제공하던 이전 제안은 현재 방향에서 제외한다.
- 아이템 맵의 완료 보상은 무작위 효과 아이템 1종이다. 아이템 수가 충분히 늘어나면 여러 후보 중 선택하는 보상으로 확장한다.
- 이미 보유·장착한 아이템도 상점과 보상 상자에 등장할 수 있으며, 등장한 중복 아이템은 F를 길게 눌러 골드로 전환한다.
- 필드의 공통 상호작용 키는 F로 통일한다. Shift는 장착 특수 아이템 사용키로 유지한다.
- Tab으로 장비창을 열고 닫는다. 장비창이 열린 동안 게임을 일시정지하고, 창 안의 모든 상호작용은 마우스로 제어한다.
- 중복 아이템은 바닥에 떨어뜨린다. 아이템 슬롯이 가득 찬 상태에서 다른 아이템에 F로 상호작용하면 장비창을 즉시 연다.
- 사망하면 이번 판의 아이템과 상점 재화를 초기화하고 처음부터 새로 모은다. 영구적으로 구매한 폼 관련 해금은 유지한다.
- 특수 아이템은 1개 장착하고 Shift로 사용한다. 거대화와 텔레포트·축지가 첫 후보이다.
- 첫 전투를 마치면 특수 아이템 후보 두 개 중 하나를 선택하는 방식을 채택한다. 첫 후보는 거대화와 축지로 제안되었다.
- 이후 몬스터 처치로 골드를 모아 진열 상품을 구매하고, 비용이 증가하는 리롤로 새로운 상품을 찾는다. 저렴한 무작위 뽑기는 v0.4에서 보류했다.
- 같은 계열의 아이템을 모으면 추가 버프가 생기는 각인 방식을 도입한다. 첫 효과는 능력치 증가 중심으로 구성한다.

각인 3종, 아이템 9개, 4칸 장착, 2개 수집 보너스는 직전 대화에서 긍정적으로 검토한 시작안이다. 개별 이름·수치와 슬롯 정책은 시험 항목으로 관리한다.

## 3. 스테이지 진행과 보상 경로

2026-11-23 사용자 보강 지시로 아래 진행 순서를 채택한다. 스테이지는 한 지역의 전체 진행, 라운드는 스테이지 안에서 선택하여 돌파하는 전투 맵을 뜻한다. 한 판이 여러 스테이지에 걸치는 범위와 다음 도전의 출발 스테이지는 미정이다.

| 순서 | 진행 | 결정 수준 |
| --- | --- | --- |
| 1 | 첫 전투 → 보상 → 특수 아이템 1개 선택 획득 | 채택 |
| 2 | 골드 맵 또는 아이템 맵을 선택하며 전반 추가 라운드 진행 | 채택, 라운드 수 추후 조정 |
| 3 | 전반 추가 라운드 종료 → 첫 상점 | 채택 |
| 4 | 첫 상점 종료 → 즉시 중간보스 전투 | 채택 |
| 5 | 중간보스 처치 → 골드 맵 또는 아이템 맵을 선택하며 후반 추가 라운드 진행 | 채택, 라운드 수 추후 조정 |
| 6 | 후반 추가 라운드 종료 → 두 번째 상점 | 채택 |
| 7 | 두 번째 상점 종료 → 즉시 메인보스 전투 | 채택 |
| 8 | 메인보스 처치 → 다음 스테이지 해금 | 채택 |

상점과 각 보스 사이에는 일반 전투 라운드를 넣지 않는다. 중간보스 후 특수 아이템 최초 획득 절차를 반복하는 것은 현재 지시에 포함되지 않는다. 다음 스테이지 진입 시 최초 보상을 반복할지는 미정이다.

전반과 후반의 라운드 수를 각각 설정값으로 둔다. ‘전반 2개·후반 2개’는 빠른 검증을 위한 예시이며 확정 개수가 아니다. 이전 10~15분 길이 제안은 중간보스가 포함된 현재 구조에서 다시 측정한다.

### 3.1 골드 맵과 아이템 맵

두 맵 모두 전투와 플랫포머 이동을 포함한다. 다음 맵 선택 전에 골드 또는 아이템 보상 아이콘을 표시한다. 매 추가 라운드마다 두 유형 중 하나를 고르는 시험안을 사용한다.

| 유형 | 완료 보상 제안 | 플레이어의 선택 이유 |
| --- | --- | --- |
| 골드 맵 | 일반 몬스터 드롭에 더해 클리어 골드 지급 | 다음 상점의 상품 구매·리롤·회복 준비 |
| 아이템 맵 | 일반 몬스터 기본 골드 드롭과 효과 아이템 보상 | 즉시 능력치 강화·각인 완성 |

보상 차이는 클리어 보상으로 구현하는 안을 권장한다. 양쪽에서 기본 골드를 얻되 골드 맵의 총 골드 수입을 더 높게 조정한다. 아이템 맵의 클리어 보상은 무작위 효과 아이템 1종으로 채택한다. 보상 상자에서 나온 아이템은 필드 획득 대상으로 처리한다. 이미 보유·장착한 중복 아이템은 바닥에 떨어뜨려 F 길게 누르기로 골드 전환할 수 있다. 슬롯이 가득 찬 상태에서 다른 아이템에 F로 상호작용하면 장비창을 즉시 연다. 아이템을 대량 추가할 개발 여유가 생기면 후보 수를 늘려 선택형 보상으로 확장한다. 현재 단계에서는 보상 선택 UI보다 무작위 1종 지급을 우선 구현한다. 가격·드롭량·완료 골드는 시험값이다.

보상은 해당 맵의 적을 모두 처치한 뒤 한 번 지급하고, 선택하지 않은 경로는 그 라운드에서 다시 방문할 수 없게 하는 안을 권장한다. 출구를 반복 통과하거나 화면을 다시 열어도 보상이 중복 지급되지 않도록 한다. 아이템 슬롯이 가득 차면 교체 또는 포기를 선택하게 하며 세부 처리 방식은 미정이다.

### 3.2 두 보상 경로의 균형

아이템이 즉시 지급되는 만큼 골드 맵에도 분명한 구매 이점이 있어야 한다. 연속 골드 선택 시 상점에서 여러 상품을 살 수 있게 하고, 연속 아이템 선택 시 각인 조합을 빠르게 만들 수 있게 조정한다. 한 골드 맵 보상만으로 반드시 구매가 가능해야 한다는 규칙은 확정하지 않는다.

검증할 경로는 전부 골드, 전부 아이템, 두 유형 혼합이다. 상점 직전에 획득하는 아이템의 효과와 골드 구매력을 비교한다. 각인 현황·보유 골드·다음 상점까지 남은 라운드를 표시하는 UI를 제안한다.

### 3.3 중간보스와 메인보스

중간보스는 전반에 모은 조합을 시험하고, 메인보스는 후반에 보완한 조합을 활용하는 전투로 구성한다. 두 보스의 구체 외형과 패턴은 최신 별도 디자인 기획과 실제 코드에서 확인한다.

중간보스 보상 시험안은 영구 재화 소량과 효과 아이템 선택 1회다. 메인보스는 다음 스테이지 해금과 영구 재화를 보상으로 주는 시험안을 둔다. 보스 보상의 수량과 추가 회복 여부는 미정이다.

상점에서 골드를 지불해 일정량의 체력을 회복하는 포션을 판매한다. 2026-11-23 사용자 동의로 채택했다. 중간보스 직전과 메인보스 직전의 두 상점 모두 회복 포션을 취급한다. 중간 수준의 회복량을 가진 비싼 포션을 상점당 1회 구매한다. 중간 회복량은 이전 답변의 해석을 현재 안으로 채택한 표현이며, 실제 회복량·가격 수치는 미정이다. 리롤해도 포션 재고는 복구되지 않는다. 무료 전회복·보스 후 자동 회복 여부는 미정이다.

### 3.4 사망과 스테이지 해금

이번 판의 아이템·상점 골드를 잃고 다시 모으는 방향을 유지한다. 중간보스 처치만으로 아이템을 유지한 사망 복귀 지점을 자동 생성하지 않는다. 다음 도전의 정확한 출발 위치는 해금 정책과 함께 결정한다.

메인보스 처치에 따른 스테이지 해금을 영구 저장하고, 해금 기록은 이후 사망에도 유지하는 안을 권장한다. 해금과 현재 판의 진입은 별개로 처리한다. 다음 중 어떤 진행 방식을 채택할지 아직 정하지 않았다.

| 후보 | 사망·진입 경험 | 선택 시 영향 |
| --- | --- | --- |
| 연속 도전 | 아이템을 유지해 다음 스테이지 진입, 사망하면 첫 스테이지부터 재시작 | 긴 판에서 조합이 누적됨 |
| 스테이지별 도전 | 해금한 지역을 허브에서 선택하고 새 조합으로 시작 | 실패 시 반복 구간이 짧아짐 |

현재의 가벼운 반복 도전 목표에는 스테이지별 도전을 우선 검토할 것을 제안한다. 아이템·골드·HP·Shift 아이템의 스테이지 간 유지와 시작 보상은 이 결정 이후 확정한다.

### 3.5 제작 범위와 구현 방식

기존 최소 범위의 보스 1종에서 중간보스와 메인보스 2종으로 확장된 계획이다. 전투 예고·패턴·충돌·다운·보상 연결을 각각 확인해야 한다. 이번 문서 수정은 기획 갱신이며 소스 구현 완료를 의미하지 않는다.

같은 전투 맵 틀에 적 배치와 완료 보상 유형을 데이터로 지정하여 골드·아이템 맵을 구성하는 방식을 권장한다. 초기에 보상 유형마다 별개의 시스템을 만들 필요는 없다. 다음 스테이지 콘텐츠는 첫 스테이지 전체 흐름 검증 후 확장하되, 해금 정보와 잠금 UI부터 연결할 수 있다. 실제 다음 스테이지가 준비되기 전에는 해금 안내와 이동 가능 상태를 구분하여 표시한다.

## 4. 영구 성장과 판 단위 성장

| 대상 | 용도 | 사망 시 처리 | 추가 결정 |
| --- | --- | --- | --- |
| 폼 해금 | 사용할 전투 수단 확장 | 유지 | 해금 조건과 가격 |
| 폼 기술 및 능력치 성장 | 폼의 지속 성장 | 구매한 성장 유지 방향 | 구현할 항목과 상한 |
| 영구 재화 | 폼 관련 구매 | 보유분 유지 시험안 | 획득 시점, 사망 시 정산 |
| 상점 재화 | 이번 판의 상품 구매·리롤·회복 | 초기화 | 드롭량과 가격 |
| 효과 아이템 | 자체 능력치 및 각인 구성 | 초기화 | 장착·보유 정책 |
| Shift 특수 아이템 | 거대화·축지 등 직접 사용 | 초기화 방향의 시험안 | 특수 아이템 해금 방식 |
| 전투 진행 | 라운드와 보스 도전 | 처음부터 재시작 | 시작 지점·허브 연출 |

영구 재화와 상점 재화는 역할을 구분한다. 상점 재화는 이번 보강에서 골드로 부른다. 영구 재화의 이름과 두 재화의 외형은 미정이다. 전투 구역 완료 시 소량, 보스 처치 시 다량의 영구 재화를 지급하는 안이 제시되었으며 지급량은 미정이다.

기존 체크포인트 부활 구현은 이번 판 초기화 규칙과 충돌할 수 있다. 최신 코드를 확인한 뒤 사망 진입점을 새 판 시작 처리로 연결해야 한다. 휴식 지점의 회복·상점 기능, 중도 종료 후 이어하기는 별도 미정 항목이다.

## 5. Shift 특수 아이템

특수 아이템은 1개 장착하고 Shift로 사용한다. 현재 구현 대상은 거대화와 축지다. 효과 아이템 장착 칸과 별도로 관리한다. 능력별로 독립된 쿨타임을 보유하고 HUD에 아이콘과 쿨타임을 표시한다. 지속시간·배율·거리·속도·쿨타임의 구체 수치는 구현 후 조정한다.

### 5.1 거대화의 전투 효과

| 구분 | 채택한 방향 | 조정할 값 |
| --- | --- | --- |
| 지속 | 일정 시간 거대화 | 지속시간 |
| 공격 | 공격 범위 확대와 피해 증가 | 판정 크기·위치와 피해 배율 |
| 이동 위험 | 이동 속도와 대시 속도 감소 | 각각의 속도 배율 |
| 피격 위험 | 피격 범위 확대 | 피격 상자 크기와 위치 |
| 방어 보완 | 피격 시 받는 피해 일정 비율 감소 | 피해 감소율 |
| 점프·지형 | 확대 상태를 고려해 발판과 통로 설계 | 점프 높이·거리와 지형 충돌 정책 |

공격 기회에는 넓고 강하게 타격할 수 있고, 이동이 느려지고 몸이 커져 공격을 피하기 어려워지는 높은 위험·높은 보상의 방향으로 구현한다. 받는 피해 감소는 이를 보완한다. ‘어느 정도 반감’은 정확히 50%로 고정하지 않고 구현 후 감소율을 조정한다. 스태거 추가 강화는 기존 후보이며 이번 지시에서 확정한 효과에 자동 포함하지 않는다.

거대화 지속 중 공격·점프·이동·대시를 사용할 수 있는 전투 버프로 해석한다. 이전의 ‘그 외 기능은 능력 사용 이후’ 임시 정책은 발동 모션 구간에 적용하는 제안으로 정리하며, 발동 모션 길이와 공격·대시 중 Shift 발동 우선순위는 미정이다. 거대화 버프 전체 동안 공격·대시를 차단하는 규칙으로 구현하지 않는다. 이 범위 해석은 사용자 확인이 가능한 구현 제안이다.

### 5.2 거대화를 고려한 맵 설계 기준

거대화 상태에서도 플랫포머 이동이 성립하는지를 앞으로 맵 제작의 중요 검증 기준으로 삼는다. 외형·공격 판정·피격 판정·지형 충돌 상자를 구분해 관리하고, 지형 충돌 상자의 확대 여부는 구현 후 이동 검증과 함께 결정한다. 이전의 지형 충돌 크기 유지 제안은 확정 정책이 아니다.

- 일반 상태와 거대화 상태 각각에서 필수 진행 경로를 검증한다.
- 발판 사이 수평 간격·높이 차·착지 폭을 거대화의 감소한 이동 속도와 실제 점프 궤적으로 확인한다.
- 대시가 필요한 구간은 감소한 대시 속도에 따른 실제 이동 거리를 확인한다. 속도와 지속시간의 조합으로 결정되는 거리도 조정 대상이다.
- 낮은 천장·좁은 문·통로·발판 아래쪽에서 확대 시 끼임·관통·강제 이동이 생기는지 확인한다.
- 점프·낙하·발판 가장자리에서 거대화가 발동하거나 종료될 때 착지 판정과 발 위치가 튀지 않는지 확인한다.
- 지형 충돌을 확대한다면 발동 위치의 공간 검사를 수행한다. 발동 거부·안전 위치 보정 등 구체 처리 방식은 별도 결정한다.
- 거대화로 공격·피격 범위가 벽 너머에 닿는 상황과 보스 결계 주변 판정을 검증한다.
- 필수 경로의 이동 가능성을 우선 보장하고, 버프가 끝날 때까지 기다려야만 진행 가능한 배치는 의도 여부를 확인한다.

### 5.3 축지

바라보는 방향으로 일정 거리 순간이동하여 적의 패턴을 피하거나 접근한다. 이동 거리와 자체 쿨타임은 설정값으로 두고 구현 후 조정한다. 순간이동 자체를 제외한 추가 공격 효과는 현재 필수 범위에 넣지 않는다.

도착 지점의 벽·맵 외부·발판 내부 겹침과 보스 결계를 검사한다. 막힌 경로를 어디까지 허용할지, 가장 가까운 안전 지점으로 이동할지 또는 발동을 거부할지는 구현 정책으로 결정한다. 순간이동 전후 별도 무적 시간은 아직 확정되지 않았다. 실제 위치 변경으로 회피하는 동작부터 검증한다.

### 5.4 능력별 쿨타임과 HUD

- 거대화와 축지는 각자 독립된 쿨타임 값을 가진다. 이전 공유 쿨타임 시험안은 이 규칙으로 갱신한다.
- HUD 또는 UI에 장착 능력 이미지, 사용 가능 상태, 남은 쿨타임을 표시한다. 숫자와 아이콘 덮개·게이지 등 구체 표현은 시험안이다.
- 거대화는 버프 지속시간과 재사용 쿨타임을 구별한다. 지속 중 상태와 남은 시간을 보여주는 UI를 권장한다.
- 쿨타임 시작 시점이 발동 시점인지 효과 종료 시점인지, 활성 중 재사용 여부와 교체·해제 상태의 시간 진행은 구현 후 조정 항목이다.
- 능력 교체 시 해당 능력의 남은 쿨타임을 별도로 보존하여 교체로 재사용 대기를 초기화하지 않는 구조를 권장한다.
- 사용 조건 미충족 시의 자원·쿨타임 소모 여부를 정하고, UI와 실제 사용 가능 판정을 일치시킨다.

거대화와 아이템·각인의 공격력 및 피해 감소를 함께 계산할 구조를 마련한다. 배율 합산·곱연산과 방어 상한은 시험값으로 기록한다. 효과 종료·장비 교체·사망·재시작 시 기본 상태에서 다시 계산해 변화가 남지 않도록 검증한다.

상점의 특수 아이템 교체 구매, 사망 시 능력 초기화와 획득 정책은 기존 조정 항목을 따른다. 도깨비감투·분신·혼불 호리병은 후속 후보로 보관한다.

## 6. 효과 아이템과 각인

### 기본 구성

각 아이템은 자체 능력치 효과와 계열을 나타내는 각인을 가진다. 같은 각인의 서로 다른 아이템을 일정 개수 장착하면 추가 능력치 보너스를 받는 방식을 시험한다.

각인은 같은 계열의 서로 다른 아이템을 모아 활성화한다. v0.5에서는 이미 보유·장착한 동일 아이템도 보상·상점에 등장하도록 채택했다. 중복 아이템은 바닥에 떨어뜨려 처리하고, F 길게 누르기로 골드 전환할 수 있다. 동일 아이템의 중복 착용을 임시 허용한다. 동일 아이템을 여러 슬롯에 장착할 수 있으며, 자체 능력치는 각 장착 수량을 반영하는 구현안을 권장한다. 중복 수량을 각인 개수로 세는지 서로 다른 아이템 종류만 세는지는 미정이다. 같은 각인의 서로 다른 아이템은 함께 착용할 수 있다.

첫 시험 구성은 각인 3종 × 아이템 3개로 총 9개, 아이템 하나당 각인 하나, 같은 각인 2개 이상에서 보너스 1회 활성화다. 3개 이상이어도 첫 버전에서는 해당 보너스를 한 번만 적용하는 구현안을 권장한다.

### 장착과 교체

효과 아이템 4칸과 Shift 아이템 1칸을 권장 시험안으로 둔다. 4칸에서는 각인 2개씩 두 종류를 완성하거나 자체 효과를 우선할 수 있다.

초기 논의의 ‘획득 즉시 전부 누적’ 방식은 장착 한도를 두는 현재 제안과 함께 적용할 수 없다. 첫 시험에서는 장착한 효과 아이템만 자체 효과와 각인 수에 반영한다. 빈칸이 있으면 즉시 장착하는 안을 권장한다. 슬롯이 가득 찬 상태에서 다른 아이템에 F로 상호작용하면 장비창을 즉시 열어 마우스로 교체·취소를 조작한다.

장비를 해제하면 즉시 바닥에 드롭한다. 다른 아이템과 교체하며 해제되는 기존 장비에도 같은 규칙을 적용한다. 바닥 아이템 재획득의 세부 규칙, 별도 보관함, 판매와 환급은 미정이다. 상점 구매 시 장비창을 여는 시점과 골드 차감 시점을 정한 뒤 구현한다.

## 7. 상점과 리롤

### 7.1 상점 공간과 판매대

사용자가 제공한 Skul 상점 스크린샷을 공간 구성 참고로 삼는다. 플레이어가 안전한 횡스크롤 상점 맵을 직접 이동하며 회복 판매대·아이템 진열대·리롤 장치와 상호작용한다. 실제 조화록의 NPC·배경·배치는 별도 제작한다.

| 구성 | 현재 안 | 상태 |
| --- | --- | --- |
| 회복 판매대 | 중간 회복량의 비싼 포션, 상점당 1회 구매 | 채택, 가격·회복 수치 미정 |
| 효과 아이템 진열대 | 무작위 상품 3개, 이름·능력치·각인·가격 공개 | 채택 |
| 리롤 장치 | 골드로 진열 상품 갱신, 사용 횟수에 따라 비용 상승 | 채택, 기본 비용·증가 폭 미정 |
| 특수 아이템 판매대 | Shift 아이템 교체 구매 기회 | 시험안, 등장 빈도·상품 수 미정 |
| 저렴한 무작위 뽑기 | 향후 확장 후보로 보관 | 보류 |

중간보스 직전과 메인보스 직전에 각각 상점을 배치한다. 상점 퇴장 후 바로 해당 보스전에 진입한다.

### 7.2 진열 상품 구매

상품은 현재 판매대에서 공개된 효과와 가격을 확인한 뒤 구매한다. 최초 진열 시 같은 화면에 같은 아이템이 겹치지 않게 구성하는 것을 권장한다. 이미 장착·보유한 아이템도 상품 후보에 포함한다. 해당 상품에 보유 중복 표시와 F 길게 누르기 골드 전환 안내를 제공한다. 구매 전 상품의 전환 정산 방식은 7.7의 미정 항목을 따른다.

구매한 상품은 해당 칸에서 품절된다. 리롤을 사용하면 품절 칸도 새 상품으로 채워진다. 골드가 충분하면 같은 상점에서 여러 상품을 구매할 수 있다.

슬롯이 가득 찬 상황의 교체·취소·환급은 아직 미정이다. 구현 시 거래 완료 시점을 명시하고 골드 차감·상품 지급·품절 처리를 함께 완료한다. 교체 선택을 여러 번 확인해도 중복 차감이나 중복 지급이 발생하지 않아야 한다.

### 7.3 리롤 규칙

- 효과 아이템 진열대의 상품을 무작위로 갱신한다. 품절 칸을 포함하여 3칸을 다시 구성한다.
- 회복 판매대와 특수 아이템 판매대는 효과 아이템 리롤 대상에서 제외한다.
- 리롤 비용은 같은 상점에서 사용할수록 증가한다. 결제 전에 이번 리롤 비용을 표시하고, 처리 후 다음 비용을 갱신한다.
- 기본 비용, 증가 폭, 증가 방식과 최대 횟수는 미정이다. 예를 들어 기본 비용에 횟수별 고정 금액을 더하는 계산을 시험할 수 있다.
- 메뉴를 닫고 다시 열어도 진열 상품·품절 기록·리롤 횟수·비용·포션 구매 기록을 유지한다.
- 다음의 별도 상점에 도착하면 리롤 횟수와 비용을 초기값으로 시작한다. 같은 상점 재접근은 새 상점 도착으로 처리하지 않는다.
- 골드 부족 등으로 리롤이 실행되지 않으면 상품·골드·리롤 횟수를 유지한다.
- 후보가 충분하면 직전 진열 상품을 제외하여 연속 재등장을 줄인다. 후보가 부족하면 직전 상품 제외 조건을 완화한다. 보유 중복 아이템도 진열 후보에 포함한다. 이 후보 선정 세부는 구현 시험안이다.

구매를 통해 비운 칸을 리롤로 채울 수 있으므로 골드 경로의 구매력과 아이템 획득량을 함께 검증한다. 반복 리롤 비용이 실제 구매 비용까지 소진하는 상황을 확인한다.

### 7.4 회복 포션 판매

중간 수준의 체력을 회복하는 비싼 포션을 골드로 판매하며, 각 상점에서 1회 구매할 수 있다. 중간보스 전 상점과 메인보스 전 상점은 별도 구매 기회를 가진다. 리롤이나 메뉴 재열기는 이미 사용한 구매 기회를 복구하지 않는다.

가격과 실제 회복량은 미정이다. 고정 HP 또는 최대 HP 비율 중 어떤 기준으로 회복할지도 추후 결정한다. 첫 구현은 구매 즉시 회복하는 방식으로 제안하며, 휴대 사용 여부는 미정이다.

회복 결과는 최대 체력을 넘지 않게 한다. 최대 체력일 때는 구매를 막고 골드와 구매 기회를 소모하지 않는 안을 권장한다.

### 7.5 상점 UI

상품에 자체 효과·각인·가격을 표시한다. 현재 각인 수와 구매·교체 후 변화를 보여준다. 예를 들어 ‘맹공 1/2 → 2/2, 공격력 보너스 활성화’와 교체로 사라지는 보너스를 안내한다.

회복 판매대에는 회복량·가격·구매 가능 또는 품절 상태를 표시한다. 리롤 장치에는 현재 리롤 비용과 보유 골드를 표시한다. 실제 포션 사용 정책이 구매 즉시 회복이면 상호작용 안내에도 표시한다.

### 7.6 무작위 뽑기 보류 기록

이전의 직접 구매보다 저렴한 뽑기와 상점당 뽑기 2회 시험안은 v0.4에서 보류한다. 현재 구현 우선순위는 포션 1회 구매·상품 3개·비용 상승 리롤이다. 이후 상점당 한 번 사용하는 저렴한 도깨비 보따리 같은 형태를 추가 검토할 수 있다.

### 7.7 중복 아이템 골드 전환

상점 진열 또는 보상 상자에서 현재 보유·장착한 것과 동일한 아이템이 등장하면 F를 길게 눌러 해당 중복 아이템을 골드로 전환할 수 있다. 비교 기준은 같은 아이템 ID이며, 같은 각인만 가진 서로 다른 아이템은 중복으로 판정하지 않는 구현안을 권장한다.

중복 아이템은 바닥 드롭 상태로 남겨 처리한다. 전환 대상은 새로 등장한 해당 아이템이다. 기존에 장착한 원본과 그 능력치·각인은 유지한다. 전환 완료 시 대상 보상 또는 상품을 소비 처리하고 골드를 한 번만 지급한다. 상점의 소비된 칸은 리롤 때 새 상품으로 채워진다. 보상 상자를 다시 열어도 이미 결정한 아이템과 수령·전환 상태를 유지하는 안을 권장한다.

골드 전환량과 등급별 차이는 구조 구현 후 조정한다. F 길게 누르기는 연속 1초 유지로 임시 고정한다. 상점 구매가·전환가·리롤 비용을 함께 조정한다.

상점 미구매 진열 상품의 정산 방식은 아직 결정되지 않았다. 구매 전 바로 전환을 허용할지, 구매 비용을 차감한 뒤 전환할지, 구매 후에만 전환할지에 따라 재화 흐름이 달라진다. 이 항목은 구현 전에 확인한다. 판매 전 상품은 구매를 완료한 뒤 전환하도록 하는 방식을 제안하되, 확정 규칙으로 적용하지 않는다. 보상 상자에서 받은 중복 아이템의 전환은 구매 비용 없이 처리한다.

### 7.8 F 상호작용 통일

| 대상 | 기본 입력 | 처리 |
| --- | --- | --- |
| NPC·상점·리롤 장치 | F 짧게 누르기 | 대화·구매·리롤 등 현재 대상 행동 |
| 보상 상자·아이템 | F 짧게 누르기 | 열기·획득·교체 확인 등 현재 단계 행동 |
| 등장한 보유 중복 아이템 | F 길게 누르기 | 골드 전환 |

현재까지 필드 상호작용에 사용하던 위 방향키 등의 입력과 UI 안내를 F로 갱신한다. 장비창 내부의 상호작용은 아래 7.9의 마우스 규칙을 적용한다. 이동 방향키·C 점프·X 공격·Z 대시·Space 폼 전환은 기존 조작 규칙을 따른다. R 재시작은 별도 재시작 기능이다.

길게 누르기는 누르고 있는 동안 진행률을 표시하고 임시 기준인 1초 도달 시 한 번 실행하는 방식이다. 다시 누르기를 기다리는 토글 동작으로 해석하지 않는다. 짧은 누르기와 긴 누르기를 함께 지원하는 중복 아이템에서는 누르는 순간 구매·획득을 먼저 실행하지 않도록 한다. 짧게 놓았을 때 일반 동작, 임계 시간에 도달했을 때 전환 동작을 처리하는 구현안을 권장한다.

전환 중 대상 이탈·대상 변경·메뉴 종료·포커스 상실 시 진행률을 초기화하는 안을 권장한다. 상자를 여는 입력과 아이템을 받는 입력은 단계별로 처리하고, 길게 누르기를 완료한 상태로 다른 대상에 접근해도 전환이 연속 실행되지 않게 키 해제 후 다시 입력받는다.

### 7.9 장비창과 바닥 아이템

#### 확정 기능

- Tab 키로 장비창을 열고 닫는다. 장비창 내부의 클릭 가능한 닫기 버튼도 제공하는 안을 권장한다.
- 장비창이 열린 상태에서 창 안의 모든 상호작용은 마우스로 제어한다. 아이템 선택·교체·확인·취소·폼 선택 및 전환 관련 조작에 F나 방향키 확인 입력을 사용하지 않는다. Tab은 창 표시를 전환하는 키로 둔다.
- 장비창에는 착용 중인 아이템, 캐릭터의 일부 능력치, 영구 획득한 메인 캐릭터 폼 관련 선택·전환 기능을 제공한다.
- 중복으로 등장한 아이템은 바닥에 떨어뜨린다. F 짧게 누르기로 중복 착용을 위해 획득하거나, F를 길게 눌러 골드로 전환할 수 있다. 슬롯이 가득 차면 기존 규칙에 따라 장비창을 연다.
- 아이템 슬롯이 가득 찬 상태에서 다른 아이템에 F로 상호작용하면 장비창을 즉시 연다. 장비창 내부에서 해당 아이템과 현재 장비를 비교하고 마우스로 처리한다.

#### 화면 구성 제안

| 영역 | 표시 및 마우스 조작 |
| --- | --- |
| 착용 아이템 | 현재 장비 슬롯, 아이템 아이콘, 선택 시 이름·효과·각인 |
| 캐릭터 능력치 | 현재/최대 HP, 공격력 보정, 피해 감소, 스태거 피해 보정 등 일부 수치 |
| 영구 획득 폼 | 획득한 폼 목록과 현재 사용 폼 표시, 마우스로 선택·전환 관련 조작 |
| 획득 대기 아이템 | 슬롯 초과로 창이 열린 경우 새 아이템과 현재 장비 비교 |
| 행동 버튼 | 장비 교체 확인·취소·창 닫기, 폼 관련 적용 |

표의 구체 능력치 목록과 버튼 배치는 시험안이다. 폼은 영구 해금 정보에서 불러오며 아이템처럼 슬롯 보상으로 새로 지급하지 않는다. 기존 Space 전투 중 폼 전환과 장비창의 폼 관리 기능을 함께 제공한다. 장비창에서는 상점 등 비전투 맵 또는 전투가 발생하지 않는 조건에서만 마우스로 영구 획득 폼을 선택·변경할 수 있다. 허용 조건에서 현재 폼을 즉시 전환하는 임시 정책을 사용한다. 전투 중에는 장비창 폼 변경을 잠근다. 폼 전환 시 착용 아이템은 변경하지 않는다. 이는 사용자의 ‘아이템 변경은 없음’을 폼 전환에 따른 아이템 변경 없음으로 해석한 것이다. 기존 장비 교체·해제 기능은 유지한다. 전투에 사용할 두 폼 구성 변경은 별도 미정이다.

#### 드롭·교체 및 거래 처리

바닥 드롭에는 아이템 ID와 고유한 드롭 인스턴스, 발생 출처, 처리 상태를 기록하는 안을 권장한다. 기존 장비는 중복 드롭의 골드 전환으로 제거하지 않는다. 처리된 드롭은 한 번만 획득 또는 전환할 수 있어야 한다.

장비창 자동 열기 시 상호작용한 아이템을 획득 대기 대상으로 유지한다. 마우스 교체를 확정하면 슬롯을 갱신하고 능력치·각인을 다시 계산한다. 취소하면 대상 아이템을 미획득 상태로 유지하는 안을 권장한다. 교체로 해제된 기존 장비는 즉시 바닥에 드롭한다. 장비창에서 개별 장비를 해제했을 때도 즉시 바닥에 드롭한다. 해제 완료 시 해당 장비의 능력치와 각인을 제거해 다시 계산한다. 드롭 위치는 캐릭터 근처의 유효한 바닥으로 정하는 구현안을 권장한다.

상점에서 중복 아이템이 보일 때 바닥에 떨어지는 정확한 시점과 비용 정산은 미정이다. 구매 후 바닥 드롭으로 처리하는 안을 제안한다. 미구매 상품의 무료 획득·전환이나 골드 중복 차감이 생기지 않도록 거래 완료 시점을 확인한다. 골드 차감·품절·아이템 전달은 한 거래에서 함께 완료한다.

#### 입력과 플레이 상태

장비창이 열린 동안 필드의 F 상호작용·길게 누르기 진행을 중단하고, 마우스 입력은 창에 전달하는 안을 권장한다. 창을 연 입력이 새 아이템 즉시 장착이나 구매 확정으로 이어지지 않게 한다. 창을 열거나 닫을 때 진행 중인 F 길게 누르기를 초기화한다.

Tab으로 장비·스탯 창을 열면 게임을 일시정지한다. 슬롯 초과 아이템 상호작용으로 자동 열린 경우에도 적용한다. 플레이어·적·보스 행동, 공격 판정·물리·발사체, 대시·무적·스태거·능력 지속시간·쿨타임 등 게임 진행 타이머를 정지하고 UI와 마우스 입력은 계속 처리한다. 닫으면 직전 상태에서 재개한다. 정지 중 실제 경과 시간을 재개 프레임 dt에 포함하지 않고, 창 열기·닫기로 판정·타이머가 초기화되지 않게 검증한다. 장비창 안에서 골드 전환 기능까지 제공할지는 미정이며 제공한다면 마우스로 제어한다.

### 7.10 장비창 폼 변경 허용 조건

| 상황 | 장비창 | 장비창 폼 변경 |
| --- | --- | --- |
| 상점 등 전투 없는 맵 | 열기 가능, 게임 정지, 마우스 조작 | 허용 |
| 몬스터·보스 또는 전투가 진행되는 맵 | 열기 가능, 게임 정지, 마우스 조작 | 잠금 |
| 몬스터·보스가 없고 이후 전투도 없는 상태 | 열기 가능, 게임 정지, 마우스 조작 | 비전투 조건 충족 시 허용 |

폼 변경은 해당 맵에서 전투를 할 일이 없는 조건을 확인한다. 장비창 일시정지 자체를 비전투 판정으로 사용하지 않는다. 화면에 보이는 적 수만 세기보다 맵의 전투 용도와 보스·웨이브·추가 적 생성 등 예정 전투도 확인하는 구현안을 권장한다. 적이 잠시 없는 상태와 라운드 전투 완료 상태를 구분하고, 라운드 클리어 후 허용 시점은 진행 처리와 함께 정한다.

조건이 충족되지 않으면 폼 선택·변경 버튼을 잠그고 사유를 표시한다. 변경 확정 시 조건을 다시 확인한다. 기존 Space 전투 중 폼 전환과 장비창 폼 선택은 별도 조작 경로다. 이번 지시는 장비창의 변경 허용 조건에 적용한다.

전투·거대화·대시 중 장비창을 열고 닫아도 직전 상태와 남은 시간이 일관되게 유지되는지 확인한다. 자동 열기에도 같은 정지 규칙을 적용하는 내용과 예정 전투 판정은 구현 세부 제안이다.

## 8. 능력치 적용 제안

아래는 구현을 돕는 계산 시험안이다. 실제 기본 능력치와 연결한 뒤 검증한다.

- 최종 공격력 = 기본 공격력 × (1 + 장착 아이템 공격력 증가 합계 + 활성 각인 공격력 증가 합계).
- 최종 스태거 피해 = 기본 스태거 피해 × (1 + 아이템·각인 스태거 증가 합계).
- 최종 최대 체력 = 기본 최대 체력 + 아이템 최대 체력 증가 합계.
- 최종 받는 피해 = 원래 받는 피해 × (1 - 최종 피해 감소율).
- 같은 능력치 증가는 우선 합산한다. 피해 감소 상한과 정수 반올림 방식은 미정이다.

아이템 장착·해제·교체 때 기본 능력치에서 전체를 다시 계산한다. 기존 최종값에 반복적으로 더하거나 곱하면 교체 후 효과가 남을 수 있다. 같은 각인 보너스는 기준을 충족했을 때 한 번만 계산한다.

최대 체력 교체 시 현재 체력을 함께 회복할지, 비율을 보존할지, 수치만 유지하고 최대값으로 제한할지는 미정이다. 반복 교체로 무한 회복하는 결과를 확인해야 한다. 판 종료 시 아이템 보정·각인·특수 아이템·쿨타임·상점 거래 기록을 초기화한다.

## 10. 결정 사항과 구현 후 조정 항목

2026-11-24 사용자 지시를 반영했다. 조정 시점이 뒤로 지정된 항목은 기획 확정을 기다리며 전체 개발을 중단하지 않고, 필요한 구조와 명시된 임시 정책부터 구현한다. 시험값과 임시 규칙은 코드 설정 및 STATUS에 기록한다.

1. **임시 변경** — 동일 아이템 중복 착용 허용. 중복 효과 계산과 각인 수량 산정은 구현안을 기록해 추후 조정한다. 보상·상점에 보유 중복 아이템이 등장하는 것은 허용하며 바닥 드롭·골드 전환 규칙을 적용한다. 효과 아이템 슬롯 4칸은 기존 시험안이며 최종 수는 아직 별도 미정이다.
2. **확정 유지** — 해제 장비는 즉시 바닥 드롭. 교체로 해제되는 장비에도 적용한다. 슬롯 초과 시 장비창 자동 열기 유지. 구매 취소·환급은 미정이다.
3. **게임 구체화 이후 결정** — 영구 재화 획득·지급 시점과 폼 구매 목록.
4. **일부 확정·구현 후 조정** — 능력별 독립 쿨타임과 아이콘·남은 시간 HUD 표시를 적용한다. 쿨타임 수치·시작 시점·사망 초기화·교체 정책은 구현 후 조정한다.
5. **거대화·축지 상세 반영** — 5절을 따른다. 거대화는 공격 범위·피해 증가, 이동·대시 감속, 피격 범위 증가, 받는 피해 감소를 구현한다. 버프 지속 중 전투·이동 허용, 발동 모션 중 제한은 구현 제안이다. 발판·통로·점프·대시 경로를 거대화 기준으로 검증한다. 축지는 일정 거리 순간이동과 자체 쿨타임부터 구현한다.
6. **구조 구현 후 조정** — 각인·아이템 이름과 수치, 피해 감소 상한, 최대 체력 변경 처리. 기존 후보와 계산식을 시험안으로 사용한다.
7. **임시 구조 구현 후 스테이지 설계·조정** — 전반·후반 라운드 수, 보상량, 목표 플레이 시간. 빠른 검증은 전반 2개·후반 2개 예시로 구성할 수 있으며 확정 개수는 아니다. 각 구간 종료 후 상점→즉시 해당 보스 순서를 유지한다.
8. **게임 구체화 이후 조정** — 다음 스테이지 진입·선택 방식, 사망 출발 위치와 스테이지 간 정보 유지. 스테이지별 도전은 현재 제안 상태다.
9. **게임 구체화 이후 조정** — 중간보스·메인보스 보상, 포션 회복량·가격·사용 방식과 보스 후 회복, 추가 콘텐츠 범위. 상점당 비싼 중간 회복량 포션 1회 구매 규칙은 유지한다.
10. **구현 이후 조정** — 리롤 기본 비용·증가 방식·증가 폭·상한·후보 부족 처리와 특수 아이템 판매 방식. 비용 상승·다음 상점 초기화 구조부터 구현한다.
11. **일부 임시 고정** — 골드 전환량 등 수치는 구현 이후 조정. F 길게 누르기는 연속 1초로 임시 고정. 미구매 상점 상품의 전환 정산 방식은 기존 미정 사항으로 유지한다.
12. **임시 지정** — 현재 아이템 맵 보상은 무작위 1종, 첫 전투 특수 아이템은 후보 2개 중 1개 선택. 아이템 대량 추가 시 보상 선택지 확대를 검토한다.
13. **일시정지·폼 변경 조건 확정** — 장비창을 열면 게임을 일시정지한다. 폼 변경은 상점 등 전투 없는 맵 또는 몬스터·보스가 없고 전투가 발생하지 않는 조건에서만 허용한다. 허용 조건에서 마우스로 선택하면 즉시 전환하는 임시 정책을 사용한다. 폼 전환에 따른 착용 아이템 변경은 없다. 장비 교체·해제 기능은 기존대로 유지한다. 이 아이템 범위 해석은 사용자 확인 가능하도록 기록한다. 표시 능력치 등 나머지 UI 세부는 시험안으로 유지한다.
14. **기존 미정 유지** — 상점 중복 아이템의 드롭 시점과 결제 처리. 해제·교체 장비의 즉시 바닥 드롭은 확정이다.
