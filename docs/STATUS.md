## 2026-11-10 화면 확대와 아래로 내려가기
- 사용자 요청 반영: 시작 시 모니터 작업 영역으로 창 최대화. 내부 1280×720 논리 좌표를 비율 유지 확대하여 이동·충돌은 기존 좌표로 처리한다. 창 크기 변경도 허용한다.
- 초록색 계단 발판을 위에서만 착지하는 통과형으로 변경. ↓를 누른 채 C를 누르면 현재 발판만 무시하고 내려가며 아래 발판/바닥에는 정상 착지한다. 회색 바닥·벽은 통과하지 않고 해당 지형에서 ↓+C는 일반 점프다.
- 하강 시작 속도 -80px/s는 임시 조정값. 하강 중 공중 추가 점프 1회, 착지 후 점프 횟수 회복.
- 검증: 자동 검사 10개 통과. 실제 SDL 창 최대화 2048×1209 확인, 논리 크기 1280×720 유지 확인. 두 종료 이벤트 검사 통과.
- 미확인: 확대 화면의 육안 확인 및 실제 키보드로 ↓+C 조작감 확인. 전체화면 독점 모드가 아니라 제목 표시줄·작업 표시줄을 유지하는 최대화 창이다.
- 다음: 사용자의 화면·하강 동작 확인 후 2단계 대시 개발.
