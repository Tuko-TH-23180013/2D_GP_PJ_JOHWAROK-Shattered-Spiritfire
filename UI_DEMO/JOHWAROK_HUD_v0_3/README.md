# 조화록 (JOHWAROK) — HUD v0.3 개발용 에셋 패키지

## 목적
《Skul》의 **정보 그룹화 원칙**에서 착안했지만, 아이콘·장식은 조화록의 도깨비/방망이/청염/한국 구름문양으로 별도 제작한 **오리지널 저해상도 스타일 가이드 에셋**입니다. 이전에 생성된 고해상도 콘셉트 아트의 픽셀 단위 재현이 아닙니다. 게임 적용을 위한 **기능 검증용 1차 PNG 리소스**이며 상용 완성 아트는 아닙니다.

## 구성
- `assets/*.png`: 배경이 투명한 UI 스프라이트 PNG, 일반 UI와 보스 UI 겸용
- `HUD_normal_preview.png` / `HUD_boss_preview.png`: 임시 배경 위에 합성한 레이아웃 미리보기. 배경은 실제 1지역 맵이 아닙니다.
- `hud_layout.json`: 1280 × 720 기준 좌표. **Pico2D 좌하단 원점**
- `demo/hud_demo.py`: Pico2D용 독립 HUD 표시/조작 예제
- `docs/IMPLEMENTATION.md`: Codex 개발 작업 순서, 변수, 상태별 업데이트 지침

## 실행
```bash
pip install pico2d
cd JOHWAROK_HUD_v0_3
python demo/hud_demo.py
```
실행 환경에 따라 Pico2D 의존 패키지 또는 폰트 파일 구성이 필요할 수 있습니다. 현재 환경에서 Pico2D 실기 실행 검증은 하지 않았습니다. 예제는 배경을 그리지 않고 HUD만 표시합니다.

## 테스트 조작
`1`: HP -10 / `2`: HP +10 / `Z`: 대시 소모 / `R`: 대시 충전 / `Space`: 무기 전환 / `B`: 보스 UI 표시·숨김 / `G`: 스태거 증가 / `ESC`: 종료

## 중요 약속
- 1지역 필수: HP, 기본/거대 방망이, 대시 2회, 보스 HP/스태거.
- A/S는 후속 구현 전에 슬롯만 표시 가능(잠금 가능).
- '조화의 공명' 게이지는 미확정이므로 포함하지 않았습니다.
- 수치 87/110, 105, 7은 **예시 UI 데이터**이며 실제 캐릭터 스탯이 아닙니다.
- 스태거가 가득 차면 보스 다운: 게임의 기존 CombatSystem에서 처리해야 하며 HUD는 결과만 그립니다.
- `Space` 전환 예약, 공격 종료 후 적용 등의 전투 규칙은 `HUD`가 아닌 플레이어 상태/전투 로직에서 처리합니다.
