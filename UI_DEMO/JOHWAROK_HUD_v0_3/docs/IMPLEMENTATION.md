# Codex 개발 지침 — 조화록 HUD v0.3

## 1. 파일 적용
게임 루트의 `assets/ui/` 아래에 패키지의 `assets/*.png`를 복사합니다. `demo/hud_demo.py`는 **독립 테스트 참고 코드**입니다. 통째로 기존 게임 루프에 복사하지 말고 `HUD.draw()`의 배치 및 렌더 로직만 현재 프로젝트 아키텍처에 통합합니다.

## 2. 데이터 연결
- HP: `player.hp`, `player.max_hp`
- 무기: 장착 슬롯 2개, `current_weapon_index`
- 대시: `dash_charges` 정수 0~2 (추후 개별 회복 시 파란 불의 투명도/진행 링 적용 가능)
- 능력: A/S 잠금 상태, 쿨타임 비율 및 아이콘
- 재화: 프로젝트에서 타입이 정해지면 카운터 연결, 미정이면 숨김 가능
- 보스: `boss.hp/boss.max_hp`, `boss.stagger/boss.stagger_max`, `boss.is_active`.

## 3. 화면 좌표
`hud_layout.json`은 **1280×720 좌하단 기준**입니다. 전체 게임 화면이 1600×900 등으로 바뀌면 `sx = width/1280`, `sy = height/720` 배율을 적용합니다. 이 패키지의 미리보기 스크린샷은 영상/아트 참고용이며 실제 좌표 데이터는 JSON을 기준으로 하세요.

## 4. 권장 렌더 순서
1. 배경·지형
2. 캐릭터·몬스터·공격 이펙트
3. 플레이어 HUD 패널 및 진행도 채우기
4. HP 프레임, 아이콘, 수치
5. 보스 활성 시 보스 패널/HP/스태거
6. 일시정지 등 오버레이

## 5. 픽셀 그래픽 규칙
- PNG는 모두 투명 배경, `RGBA`.
- UI 위치는 정수 픽셀에 스냅하도록 권장.
- 스케일은 가능하면 정수 배율 및 최근접 보간 사용.
- 16:9 기준. HUD는 화면 하단부에 집중, 전투 중앙을 가리지 않기.
- 한글 표시와 폰트는 게임 프로젝트 폰트 사용. 현재 데모 보스명은 영문 로마자 임시 표기.

## 6. 플레이 검증 체크리스트
- [ ] HP 0~최댓값에서 바가 영역을 넘지 않는다.
- [ ] 무기 2종 전환 시 강조 테두리만 이동하고 슬롯 위치는 고정된다.
- [ ] 대시 2/1/0 단계가 구별된다.
- [ ] 스태거가 가득 찼을 때 HP 감소와 별개로 다운 처리가 발생한다.
- [ ] 보스 종료 후 상단 UI가 즉시 사라진다.
- [ ] 해상도 변경 후 HUD가 잘리거나 캐릭터를 과도하게 가리지 않는다.
- [ ] 최종 게임의 한글 폰트에서 문자 깨짐이 없다.
