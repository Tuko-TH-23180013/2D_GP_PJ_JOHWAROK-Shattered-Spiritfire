# 조화록 — JOHWAROK: Shattered Spiritfire

Python/Pico2D 기반 1인 대학 게임 프로젝트입니다. 일반 몬스터 7종·중간 보스·메인 보스의 **데모 스프라이트**와 7개 임시 맵을 연결했습니다. 음원과 최종 밸런스는 아직 적용하지 않았습니다.

## 현재 실행 모드: 7개 데모 맵

`main.py`를 실행하면 `MapGame`으로 시작합니다. 아래 과거 단계 설명의 장승마을 연속 맵은 `Game`으로 회귀 검사에 보존했습니다. 현재 경로는 다음과 같습니다.

| 순서 | 맵 | 등장 몬스터 |
|---|---|---|
| 1 | 마을 진입로 | 깨진 장승귀, 탈붙이 |
| 2 | 장독 골목 | 장독귀, 솟대새 원령 |
| 3 | 하회탈 마당 | 하회탈 수호 무사: 내려베기·찌르기 |
| 4 | 혼불 쉼터 | 세이브 포인트 |
| 5 | 버려진 곡간 | 잔불 도깨비, 뒤주귀 |
| 6 | 숲길 방책 | 지게귀, 깨진 장승귀 |
| 7 | 수호신 사당 | 타락한 도깨비 수호신: 휘두르기·돌진 |

적을 모두 처치하고 사망 연출이 끝나면 출구가 열립니다. 오른쪽 보라색 문 앞에서 **↑**로 다음 맵에 이동하며 HP/무기는 유지됩니다. 중간 보스 처치는 다음 맵을 열고 메인 보스 처치는 승리로 처리합니다. 상단 경로도에서 현재 맵과 완료 맵을 확인할 수 있습니다.

쉼터 중앙의 파란 장승 앞에서 **↑**로 세이브 포인트를 활성화하세요. **R**은 활성화한 쉼터(없으면 첫 맵)에서 최대 HP·기본 무기·대시 2회로 재시작합니다. 이후 맵의 적은 다시 생성됩니다. 활성화 자체로 HP를 회복하지 않으며 **저장은 현재 실행 중에만 유지**됩니다. 파일 저장/불러오기는 이번 범위에 포함하지 않았습니다.

`Sprite_sheet/Monsters_sprite_demo`는 제공 원본, `Sprite_sheet/Monster/{normal,mid,main}`은 런타임 데모 리소스입니다. 하회탈 다운/기상 보완 시트는 imagegen으로 추가 제작했습니다. 각 폴더 JSON의 크기·피벗·실제 몸 높이로 배율을 계산하며, 원본 PNG를 덮어쓰지 않았습니다. 사망 시트는 한 번 재생하고 제거합니다. 잔불 투사체의 혼불은 임시 도형 효과입니다.

`monsters.py`에 일반 몬스터 임시 전투값, `demo_bosses.py`에 중간 보스와 메인 보스 행동, `map_route.py`에 맵·등장 몬스터 배치를 모았습니다. 복잡한 지형 길 찾기·후퇴 반격 확장 패턴·추가 음원은 미적용입니다. 아래 기존 조작(이동·2단 점프·아래+C·X·Z·Space)은 그대로 사용합니다.

## 8단계 데모 스프라이트 적용

사용자 제공 `Sprite_sheet/JOHWAROK_main_Sprite_Demo`의 원본을 보존해 사용합니다. **최종 확정 에셋이 아닌 데모**입니다. 주인공의 대기·달리기·상승/정점/낙하·대시·기본 3타·공중·거대 2타를 게임 상태에 연결했습니다. 160×160 셀의 발 피벗 (80,133)을 사용하고, 현재 임시 외형 배율은 0.9입니다.

공격 포즈는 기존 Attack의 STARTUP/ACTIVE/RECOVERY에 맞춥니다. 데모 프로그램의 다른 콤보/대시 규칙은 가져오지 않았으며 기존 충돌 크기·공격 시간·피해·입력 규칙을 유지합니다. 이미지의 무기 궤적과 실제 판정 범위가 완전히 일치하는지는 추후 조정 대상입니다. **F2**로 플레이어 충돌 상자를 확인할 수 있습니다.

거대 무기의 이동/공중 포즈는 공통 프레임, 거대 지상 2타는 동봉 데모의 프레임 조합을 사용합니다. 주인공 전용 사망 포즈가 없어 마지막 포즈를 유지합니다. 현재 기본 모드의 일반 적·보스는 몬스터 데모 시트로 표시됩니다.

데모 배경은 원본에 포함된 제목/조작 안내를 제외한 풍경 부분을 잘라 느린 카메라 스크롤에 사용합니다. 데모 장승은 정지 연습 대상에 적용했습니다. 동봉 DejaVu 폰트로 현재 조작·HP·무기·사망/승리 안내를 표시하며 라이선스는 `assets/font-license.txt`에 보존했습니다. 음원은 제공되지 않았습니다.

이미지와 폰트는 창 생성 후 한 번 로드해 재시작 시에도 재사용합니다. 모든 경로는 소스 위치 기준이며 기존 Pico2D 의존성 외에 새 패키지를 설치하지 않습니다. `sprite_animation.py`는 프레임 선택, `sprite_renderer.py`는 로드·그리기를 담당합니다.

## 7단계 오래된 도깨비

보라색 보스 입구(x=3000 부근)에서 **↑**를 누르면 전투장으로 들어갑니다. 입장 시 현재 HP와 무기를 유지하고 공격·입력·대시 상태는 초기화합니다. 전투장 왼쪽은 막히며 **R**은 체크포인트(미활성화 시 시작점)로 돌아가 보스를 초기화합니다. 먼저 장승 체크포인트를 활성화하세요.

보스는 가까이 접근해 방망이를 휘두른 뒤 전방 돌진을 번갈아 사용합니다. 노란 준비는 휘두르기, 자주색 준비는 돌진이며 판정 중에는 빨간 범위가 표시됩니다. 전투 중 화면 위 큰 빨간 막대는 보스 HP, 보라 막대는 스태거입니다.

일반 타격으로는 보스 패턴이 끊기지 않습니다. 스태거가 가득 차면 2초 다운되고 0.7초 기상 후 복귀합니다. 다운·기상 중에도 정상 피해를 받습니다. 다운 중 스태거는 누적하지 않으며, 기상 중 누적도 임시로 차단했습니다. HP 0이면 초록 승리 패널과 제목 표시줄 안내가 나오고 전투가 멈춥니다. **R**로 다시 도전할 수 있습니다.

패턴은 인계 문서의 예시를 임시로 구현했습니다. HP 500·스태거 120·휘두르기 피해 22/준비 0.65초·돌진 피해 28/준비 0.85초 등은 추후 조정합니다. 사망·승리 안내는 화면과 제목 표시줄에 표시됩니다. 보스 전용 외형과 애니메이션은 후속 작업입니다.

## 6단계 장승마을 진행

오른쪽으로 이동하며 시작 구역 → 발판/전투 구역 → 체크포인트 → 보스 입구로 진행합니다. 보스 전투장을 포함해 가로 4400px 임시 맵이며 x=1070 부근의 장애물은 C 2단 점프로 넘을 수 있습니다. 카메라는 플레이어를 따라가고 맵 끝에서 멈춥니다. 현재 배경은 직사각형과 임시 장승 표식입니다.

x=2500 부근의 파란 장승 가까이에 서서 **↑**를 누르면 초록색으로 변하며 체크포인트가 활성화됩니다. 근처에서는 제목 표시줄에도 안내가 나타납니다. 활성화 자체는 HP를 회복하지 않으며 재시작 위치만 기록합니다.

**R**은 마지막으로 활성화한 체크포인트에서 재시작합니다. 활성화 전에는 시작점으로 돌아갑니다. 기본 무기·최대 HP·대시 2회로 복원하고 공격·예약·속도·입력·적·연습 대상을 초기화합니다. 체크포인트 기록은 실행 중에만 유지하며 게임을 닫으면 사라집니다.

오른쪽 보라색 문은 보스 입구입니다. 도달하면 제목 표시줄에 ↑ 입장 안내가 나옵니다. 상세 배치·시각 표현·수치는 스프라이트와 밸런스 작업 때 조정합니다.

## 5단계 생존 전투

오른쪽의 적에게 다가가면 추적하고 공격합니다. 노란 준비 동작을 보고 Z로 피하거나 X로 반격하세요. 빨간 공격 범위는 실제 판정 구간에만 표시됩니다. 플레이어 HP는 왼쪽 위 빨간 막대, 적 HP와 스태거는 적 위 막대로 표시합니다.

일반 피격으로 현재 공격·콤보는 끊기지 않습니다. 적도 일반 타격에는 공격을 유지하지만 스태거가 가득 차면 경직되며, 경직이 끝나면 스태거가 초기화됩니다. 대시·전환·피격 후 무적은 별도로 관리합니다.

플레이어 HP가 0이면 사망 패널과 제목 표시줄 안내가 나타납니다. **R**은 생존/사망 중 모두 체크포인트 또는 시작점에서 전투를 재시작합니다. 기본 무기·HP·대시 충전·적·연습 대상·공격·전환 예약과 입력을 초기화합니다. 적을 처치하면 사라지고 R로 다시 연습할 수 있습니다.

임시값: 플레이어 HP 100, 적 HP 120, 적 피해 15, 준비 0.45초, 피격 후 무적 0.5초, 적 스태거 한계 60·경직 0.6초. 세부 수치는 스프라이트 적용과 밸런스 작업 때 조정합니다. 현재 적은 같은 높이에서 접근하며 벽을 통과하지 않습니다. 발판 점프나 복잡한 길 찾기는 아직 없습니다.

## 4단계 무기 전환

**Space**로 기본 방망이와 거대 방망이를 전환합니다. 기본은 빠른 지상 3타, 거대는 느리고 넓은 지상 2타이며 공중에서는 각각 단일 공격을 사용합니다. 왼쪽 위 작은 파란 막대는 기본, 큰 황갈색 막대는 거대 방망이입니다. 제목 표시줄에도 무기와 예약 여부를 표시합니다.

공격 중 Space는 한 번만 예약하고 공격 종료 후 전환합니다. 전환 예약이 있으면 다음 콤보 예약보다 먼저 처리하며 이전 공격과 콤보 예약을 지웁니다. 후딜 Z로 공격을 취소한 경우에도 예약 전환을 실행합니다. 대시 중에도 전환 가능하며 대시 이동은 유지합니다.

전환 시간은 임시 0.18초이고 이 동안 공격·재전환은 차단하지만 이동·점프·대시는 가능합니다. 시작 0.10초는 별도의 전환 무적이며, 기존 대시 무적은 전환 시작 시 끝납니다. 파란 사각형 불꽃은 에셋 도입 전 임시 도깨비불 표현입니다. Space+X는 전환 우선, X+Z는 대시 우선입니다. R 초기화는 전환 예약과 전환 무적도 제거합니다.

거대 방망이의 임시 지상 피해는 24/36, 범위는 120/150px, 공중 피해는 26입니다. 시간·피해·스태거 등은 `weapon_data.py`에서 조정합니다. 아직 실제 스프라이트 애니메이션은 연결하지 않았습니다.

## 3단계 기본 공격

갈색 연습 대상 가까이에서 **X**로 공격합니다. 기본 방망이 지상은 3타 콤보, 공중은 단일 공격입니다. 공격 중 X를 다시 누르면 다음 공격 1회를 예약하며, 누르고 있기만 하면 반복하지 않습니다. 공격이 완전히 끝난 뒤 새로 누르면 1타부터 시작합니다. **R**은 전투 전체를 초기화합니다.

머리 위 표시가 노랑이면 준비, 주황이면 판정, 보라면 후딜입니다. 주황색 테두리 공격 범위는 판정 구간에만 나타납니다. 대상 위 빨강 막대는 HP, 보라 막대는 스태거입니다. HP가 0이면 대상이 사라지며 R로 다시 연습할 수 있습니다.

**확정 규칙(2026-11-10): 준비·판정 중에는 대시 불가, 후딜에서는 대시 취소 가능.** 대시 충전이 없거나 재사용 간격이면 공격과 예약을 유지합니다. X+Z 동시 입력은 Z 우선으로 X를 무시합니다. 공격을 시작하면 기존 대시 무적은 끝나지만 대시 이동은 유지됩니다. 공격 중 바라보는 방향은 고정하며, 지상 공격 중 점프하거나 공중 공격 중 착지해도 시작한 공격 종류는 유지됩니다.

공격 데이터는 `attack.py`와 `weapon_data.py`에 분리했습니다. 기본 지상 피해 10/12/18, 공중 피해 12, 연습 대상 HP 200·스태거 한계 60·경직 0.6초 등은 임시값입니다. 동일 프레임 여러 공격의 우선순위는 임시로 전달 순서이며 대상당 피해는 1회입니다. 게임 루프에서는 플레이어 타격을 먼저 해결합니다. 갈색 연습 대상은 AI가 없는 고정 표적입니다.

## 2단계 대시

**Z**를 누르면 바라보는 방향으로 대시합니다. 지상·공중에서 충전 2회를 공유하며 착지 없이 1초마다 한 개씩 순차 회복합니다. Z를 계속 누르고 있어도 자동 반복하지 않습니다. 왼쪽 위 두 칸은 남은 충전이며 제목 표시줄에 충전 회복 시간과 위험 구역 접촉 횟수를 표시합니다.

대시 시작 0.08초는 흰색 무적, 나머지 이동 구간은 주황색으로 피격 가능합니다. 이전 연습장의 위험 구역은 장승마을 맵에 배치하지 않았습니다. 실제 HP 피해는 적의 공격으로 받습니다.

대시 중 C 점프에 성공하면 대시 이동은 유지하고 무적만 즉시 끝냅니다. ↓+C 발판 하강도 무적을 끝냅니다. 실패한 점프 입력은 무적을 끝내지 않습니다. 대시 방향은 시작 시 고정되며 중력·수직 이동은 유지합니다.

임시 수치: 대시 속도 850px/s, 이동 0.20초(막힘 없을 때 170px), 무적 0.08초, 대시 종료 후 다음 대시까지 0.08초 간격, 한 충전 회복 1초. 이동 중이거나 재사용 간격 중에 누른 Z는 예약하지 않습니다.

## Windows 실행

확인 환경: Python **3.12.10**, Pico2D **1.5.1**, PySDL2 **0.9.17**, PySDL2-DLL **2.32.10**. 기존 PC에서 설치를 확인한 조합을 사용했습니다. 수업 지정 버전과의 일치 여부는 미확인입니다.

프로젝트 폴더에서 PowerShell로 실행합니다. 이미 `.venv`를 구성했다면 마지막 명령만 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

VS Code 인터프리터도 `.venv\Scripts\python.exe`로 선택합니다. 현재 PC에서는 `python`이 3.12.10으로 실행되지만 `py -0p`는 설치된 Python을 찾지 못하므로 `py` 런처에 의존하지 않습니다.

게임 창은 모니터 작업 영역에 맞춰 최대화하여 시작합니다. 내부 좌표는 1280×720으로 유지하고 화면 비율을 보존해 확대합니다. 모니터 비율에 따라 여백이 생길 수 있으며 창 크기를 바꿔도 이동·충돌 수치는 유지됩니다.

**좌우 방향키**로 이동하고 **C**를 눌러 점프합니다. 공중에서 C를 다시 누르면 한 번 더 점프할 수 있으며 착지하면 횟수가 회복됩니다. C를 계속 누르는 것만으로 반복 점프하지 않습니다. 초록색 발판 위에서 **↓를 누른 채 C**를 누르면 아래로 내려갑니다. 내려가는 동안에는 공중 점프가 한 번 남습니다. 바닥·단단한 지형에서 ↓+C는 일반 점프로 처리합니다. **Esc** 또는 **창 닫기**로 종료합니다.

플레이어의 파란색은 지상, 초록색은 공중 상태입니다. 노란 테두리는 실제 충돌 상자이며 외형보다 작습니다. 검은 눈 표시가 바라보는 방향을 나타냅니다. 초록색 발판은 위에서만 착지하는 통과형 발판이고, 회색 바닥·벽은 모든 방향에서 막히는 단단한 지형입니다.

좌표는 왼쪽 아래 원점의 픽셀 단위이며 시간은 초 단위입니다. 긴 프레임의 dt는 최대 0.05초로 제한합니다. 창 크기·60 FPS 목표·dt 상한은 초기 개발용 임시 설정입니다.


실행 검사는 실제 창을 두 번 열어 Space·X를 주입하고 각각 60프레임을 그린 뒤 Esc와 SDL 종료 이벤트를 주입합니다. 두 경로의 정상 종료를 확인했으며, 화면의 시각적 표시와 실제 키보드·닫기 버튼 조작은 직접 확인해야 합니다.

자동 검사 67개는 기존 회귀와 보스 패턴·다운/기상·정상 피해·사망 재도전·승리·FPS별 피해 일관성을 확인합니다. 실제 창 검사에서는 입장·다운/기상·사망·체크포인트 재도전·승리 표시를 확인합니다. 보스 검사에서는 경계 상태를 빠르게 재현하기 위해 위치/HP/스태거를 지정하며, 자동 승리 테스트는 플레이어 무적 fixture를 사용합니다. 최종 난이도나 사람의 실전 클리어를 검증한 것은 아니므로 직접 조작감과 전체 전투 흐름을 확인하세요.

이동 속도 300px/s, 점프 속도 620px/s, 중력 1800px/s², 최대 낙하 속도 900px/s는 임시값입니다. 물리는 최대 1/240초씩 나누어 갱신하고 좌우·상하 충돌을 분리합니다.

자동 검사는 데모 시트 크기·클립 좌표·발 기준점·상태별 포즈·리소스 재사용을 포함해 73개입니다. `check_demo_sprites.py`는 실제 창에서 25프레임을 좌우로 그리고 임시 폴더에 화면 캡처를 저장합니다. 이 검사는 최종 스프라이트 품질이나 밸런스 검증을 대신하지 않습니다.
