# 조화록 · 장승마을 스프라이트 데모

## 실행

Windows에서 ZIP을 풀고 `demo.py`가 있는 폴더를 VS Code로 연 뒤 터미널에서 실행합니다.
Python과 Pico2D가 준비되어 있다면 두 번째 줄부터 실행하면 됩니다.

```powershell
py -m pip install -r requirements.txt
py demo.py --auto
```

직접 조작하려면 `py demo.py`로 시작하거나 실행 중 F1을 누릅니다.

| 키 | 기능 |
|---|---|
| ← / → | 이동 |
| C | 점프, 공중에서 다시 눌러 2단 점프 |
| X | 공격. 후딜이 끝나면 다시 눌러 다음 타 연결 |
| Z | 지상·공중 공용 2회 충전 대시 |
| Space | 기본 방망이 ↔ 거대 방망이 |
| F1 / R / Esc | 자동 시연 전환 / 초기화 / 종료 |

## 캐릭터 시안

| 시안 | 실루엣과 장식 |
|---|---|
| A 장승마을 길잡이 | 아이보리 저고리, 남색 치마, 붉은 허리끈, 황동 방울. 데모에 적용한 방향 |
| B 산길 사냥꾼 | 짧은 털깃과 민소매 겉옷, 좁은 바지, 옥 장식 |
| C 마을 의식 수호자 | 넓은 흰 소매, 적갈색 치마, 길게 늘어진 부적 |
| D 혼불 방랑자 | 어두운 비대칭 옷자락, 청록 자수와 방망이에 붙은 도깨비불 |

네 시안과 동작 원화는 첨부 캐릭터 이미지에서 긴 검은 머리, 작은 뿔과 한복을,
동작 참고 시트에서 달리기·대시의 실루엣과 타격 궤적을 참고해 제작했습니다.

## 전투

| 무기 | 지상 공격 | 공중 공격 |
|---|---|---|
| 기본 방망이 | 가로 휘두르기 → 올려치기 → 내려찍기 | 대각선 내려 휘두르기 |
| 거대 방망이 | 양손 내려치기 → 더 느리고 강한 내려찍기 | 같은 공중 포즈에 더 긴 준비와 회수 |

각 타는 준비 → 판정 → 후딜로 구성됩니다. 후딜 종료 뒤 0.38초 안에 X를
다시 누르면 다음 타로 넘어갑니다. 공격 도중의 X 재입력은 저장하지 않습니다.
X와 Z가 동시에 들어오면 Z를 먼저 처리합니다. 준비·판정 중 Z는 공격을 유지하며
이동하고, 후딜 중 Z는 후딜을 취소합니다. 공격 도중 Space는 전환을 예약하고,
대시 중 Space는 즉시 전환합니다. 공격 방향과 지상·공중 포즈는 공격 시작 시 고정됩니다.

장승은 HP와 스태거를 표시합니다. 공격당 최대 1회 피해를 받고, 스태거 65에
도달하면 잠깐 내려앉습니다. 콤보 시간, 피해량, 스태거, 대시 회복은 시연용 수치입니다.
피격을 가하는 적과 거대 방망이의 전용 이동·공중 스프라이트는 이후 제작 범위입니다.

## 스프라이트

`assets/hero.png`는 투명 PNG입니다. 160×160 픽셀 셀 25개를 5×5로 배치했습니다.
발 피벗은 각 셀의 좌상단 기준 (80, 133)이며, 왼쪽 방향은 수평 반전합니다.
Pico2D에서 자를 때 PNG 행 번호를 아래에서부터 세는 좌표로 바꿉니다.
번호는 원본 PNG의 좌상단부터 0으로 셉니다.

| 프레임 | 동작 |
|---|---|
| 0–1 | 대기 |
| 2–5 | 달리기 |
| 6–8 | 점프 상승 / 정점 / 낙하 |
| 9 | 대시 |
| 10–12 | 기본 1타 |
| 13–15 | 기본 2타 |
| 16–18 | 기본 3타 |
| 19–21 | 공중 공격 |
| 22–24 | 거대 방망이 공격 |

GIF는 `demo.py`의 전투 상태와 자동 시연 입력을 사용해 별도 렌더링했습니다.
제공 환경에서는 Pico2D 패키지를 설치할 수 없어 실제 게임 창의 실행 확인은 Windows에서 필요합니다.
