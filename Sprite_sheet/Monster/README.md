# 몬스터 런타임 데모 리소스

`normal`, `mid`, `main`은 사용자 제공 `../Monsters_sprite_demo`의 분류를 유지한 게임용 복사본이다. 원본 PNG는 변경하지 않았다. 각 JSON의 frame_size, pico2d_pivot, reference_body_height_px로 원점과 표시 배율을 계산한다. 프레임 수나 캔버스 크기를 하드코딩하지 않는다.

추가 제작: `mid/hahoe/sprites/hahoe_reactions_demo.png`는 imagegen으로 원본 하회탈 무사의 정체성을 참고해 만든 **데모** 피격/다운/기상/대기 4포즈다. 생성 원본 2172×724를 그대로 보존하며 가로 543×724 셀, 발 기준 y=585(상단 기준)을 사용한다. 전투 충돌 크기와 다운 시간은 코드가 결정한다. 최종 픽셀 밀도/디테일 일치 여부는 후속 아트 조정 대상이다.

제공 시트의 미리보기 시간은 전투 수치가 아니다. 공격 포즈는 실제 Attack.phase를 따르고, 사망 7프레임만 메타데이터의 시간을 따라 한 번 재생한다. 하회탈 후퇴 반격 확장 시트는 보존하되 이번 두 패턴 구현에는 사용하지 않는다.
