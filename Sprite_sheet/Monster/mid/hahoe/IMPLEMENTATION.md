# 하회탈 수호 무사 구현 지침

중간 보스. 근거리 내려베기와 조금 더 먼 거리의 짧은 찌르기를 구분한다.

## 상태와 패턴

대기/접근 → 패턴 선택 → 예고 → 타격 → 회수. 가까우면 내려베기, 한 걸음 밖이면 찌르기, 두 거리 밖이면 접근을 계속한다. 공격 중에는 패턴 변경과 방향 전환을 잠근다.

내려베기는 바로 앞의 비교적 넓고 높은 영역을 사용한다. 찌르기는 좁고 긴 영역으로, 한 걸음 이동한 구간까지만 검사한다. 후퇴 후 반격은 확장 후보로 둔다. 활성화할 경우 후퇴 자체는 피해를 주지 않고 복귀 횡베기에서만 공격을 생성한다. 전용 다운·기상 시트가 필요하면 현재 코드의 상태와 맞춘 뒤 임시 표시를 명시한다.

일반 피격 중에도 현재 공격은 유지한다. 보스 분류의 기존 다운·기상·스태거 규칙을 사용하고, HP 0 전이를 다른 반응보다 우선한다.

## 시트와 프레임

- Pico2D 셀 `240×240`, 좌하단 기준 피벗 `(120, 20)`. 원본은 오른쪽 방향이다.
- 시간은 시연용 초깃값이다. HP, 피해, 감지 거리, 이동 속도와 히트박스 크기는 기존 값과 충돌 로그를 기준으로 조정한다.

## Codex 구현 순서

1. 기존 게임에서 적 생성, 업데이트·그리기, 지형 충돌, 피해 처리, 씬 초기화의 진입점을 먼저 찾는다. 현재 클래스·상태와 아래 사양의 대응을 확인한 뒤 게임의 정상 스폰 경로에 한 종씩 연결한다.
2. 공용 적 클래스와 기존 `Attack`/`CombatSystem`을 재사용한다. 적에게 맞을 수 있는 몸 판정과 적이 내는 공격 범위는 별개로 관리한다. 공격 1회당 대상별 적중 기록을 유지하고 게임의 무적·동일 프레임 다중 히트 규칙을 적용한다.
3. 상태 타이머는 델타 시간으로 갱신한다. 발사·타격 활성화처럼 한 번만 일어나는 동작은 상태 진입 또는 시간 경계 통과 시 실행한다. 시트의 표시 시간은 임시값이다. 코드에 이미 같은 패턴의 실제 시간이 정의되어 있으면 그 값을 우선 사용한다.
4. HP가 0이면 `death` 상태를 한 번만 시작한다. 진행 중인 이동과 공격 범위·접촉 피해·예약 발사를 즉시 끝내고 추가 피격을 막는다. 현재 월드 피벗과 방향을 유지하며 사망 시트 0~6을 1회 재생한다. 6번은 완전 투명이다. 재생을 마친 뒤 기존 삭제 큐에서 제거하고, 보상·카운트·클리어 신호는 게임의 기존 시점에 한 번만 전달한다. 씬을 재시작해도 이전 사망 객체나 공격이 남지 않아야 한다.

## Pico2D에서 시트 읽기

ZIP 최상위 `sprites.json`의 `path`는 압축 해제 루트에 대한 상대 경로다. 각 행은 단일 가로 스트립이며 번호는 0부터 센다. `x, y`는 월드 피벗, `scale`은 표시 배율이다. 카메라 좌표 변환이 있다면 프로젝트의 변환을 적용해 그린다.

```python
w, h = sheet["frame_size"]
px, py = sheet["pico2d_pivot"]
flip = "h" if facing < 0 else ""
draw_x = x + (w / 2 - px) * scale * facing
draw_y = y + (h / 2 - py) * scale
image.clip_composite_draw(frame_index * w, 0, w, h, 0, flip,
                          draw_x, draw_y, w * scale, h * scale)
```

지상형의 월드 피벗은 발 접지점, 공중형은 몸 중심이다. 프레임 경계나 투명 여백을 공격 판정으로 쓰지 않는다. 공격 스트립에는 대기·이동·예고·타격·회수의 키포즈가 있다. 일반 스트립의 0~4번을 매 공격 때 전부 흘려보내는 대신 현재 AI 상태가 사용하는 프레임을 표시한다.


## 완료 확인

- 정면과 뒤쪽, 근거리와 한 걸음 밖에서 각 패턴 선택을 확인한다. 대시 무적으로 피할 수 있고, 회수 중에는 어느 방향에서도 공격 판정이 남지 않는다. 확장 후보를 활성화하면 후퇴 중 피해도 별도로 확인한다.
- 대기·예고·타격 중 각각 HP를 0으로 만들어 공격이 즉시 끝나고 사망 7컷이 한 번만 재생되는지 확인한다.
- 좌우 반전에서 발/몸 피벗과 공격 방향이 함께 맞는지, 씬 재시작 시 같은 적을 다시 스폰할 수 있는지 확인한다.
